# 🎙️ Органайзер — голосовой помощник для бизнеса

## Что это
Программа, которая записывает твой голос, распознаёт задачи и **сама ставит их в Яндекс.Календарь**.

Ты говоришь: «Напомни купить хлеб завтра в 10 в магазине» — и задача сама появляется в календаре с уведомлением.

---

## Как установить (2 минуты)

1. Установи **Pydroid 3** из Play Store (оранжевая иконка)
2. Открой ссылку: `https://github.com/Vladimir-1337/VoiceAgent/blob/main/install_organizer.py`
3. Скопируй **весь код** → вставь в Pydroid → нажми **Run ▶️**
4. После установки открой `main.py` в папке `VoiceAgent` → Run
5. При первом запуске введи свои логин и пароль приложения Яндекса

---

## Как получить пароль приложения Яндекса
1. Зайди на [passport.yandex.ru](https://passport.yandex.ru)
2. **Пароли приложений** → **Создать пароль** → выбрать **Календарь**
3. Скопируй 16 букв — это и есть пароль приложения

## Как пользоваться

| Скажи | Результат |
|-------|-----------|
| «Напомни купить хлеб завтра в 10 в магазине» | Задача в календаре + уведомление |
| «Приказываю купить хлеб завтра в 10 приказываю позвонить брату в пятницу» | Две задачи |
| «Встретиться с братом завтра в 12 в офисе» | Задача с участником |
| «Напомни сдать анализы в гематесте в пятницу в 9» | Задача с адресом |

## Возможности
- 🎤 Распознавание голоса (Whisper)
- 📅 Выгрузка в Яндекс.Календарь
- 👤 Участники: «с братом», «с Вовой»
- 📍 Адреса: «в офисе», «на складе», «в гематесте»
- ✂️ Разделение фразы на несколько задач («Приказываю»)
- 🔄 Автообновление при выходе новой версии
- 📝 Отправка репорта об ошибке (кнопка 0 в Мониторинге)
- 📱 Работает на всех Android-телефонах (Xiaomi, Samsung, Huawei, Pixel)
