# Органайзер — голосовой помощник для бизнеса

## Что это
Программа, которая записывает твой голос, распознаёт задачи и сама ставит их в Яндекс.Календарь.

## Как установить
1. Установи Pydroid 3 из Play Store
2. Скопируй папку VoiceAgent в /storage/emulated/0/
3. Открой main.py в Pydroid → Run
4. При первом запуске введи логин и пароль приложения Яндекса

## Как получить пароль приложения
1. Зайди на passport.yandex.ru
2. Пароли приложений → Создать пароль → Календарь
3. Скопируй 16 букв

## Как пользоваться
1. Открой диктофон, скажи фразу
2. Например: «Напомни купить хлеб завтра в 10 в магазине»
3. Задача сама появится в Яндекс.Календаре

## Что работает
- «Напомни» — задача сразу в календарь
- «Приказываю» — разделение на несколько задач
- «С собой» — список вещей
- Места: «в офисе», «на складе», «в гематесте»
- Люди: «с братом», «с Вовой»
